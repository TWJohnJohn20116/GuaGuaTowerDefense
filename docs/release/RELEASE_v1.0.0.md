## v1.0.0 - 首次公開發布

瓜瓜塔防正式發布！

### 遊戲特色
- 多種防禦塔：基礎塔、冰霜塔、火焰塔、毒液塔、機槍塔、金幣塔等
- 豐富地圖：多張精心設計的地圖 + 隨機地圖生成
- 升級系統：防禦塔可升級強化，解鎖專屬技能
- AI 自動戰鬥：平衡、經濟、進攻、防守四種策略
- 無盡模式：無限波次挑戰你的極限
- 成就系統：完成各種挑戰解鎖成就
- 自訂主題：多種主題配色自由切換
- 皮膚系統：自訂防禦塔和敵人外觀
- 完整教學：新手引導快速上手

### 安裝說明
1. 下載下方的 `瓜瓜塔防_1.0.0_x64-setup.exe`
2. 執行安裝程式，依照指示完成安裝
3. 從開始選單或桌面捷徑啟動遊戲

### 系統需求
- Windows 10 (64-bit) 以上
- WebView2 Runtime（安裝程式會自動安裝）
