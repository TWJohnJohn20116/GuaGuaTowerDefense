## DialogueLine 格式

```typescript
{
  speaker: 'AI 副官 艾莉絲',
  text: '繁體中文台詞，每句 1–3 行，避免過長。',
  expression: 'normal' | 'happy' | 'angry' | 'surprised' | 'serious',
}
```

## 每關篇幅

- **preBattleDialogue**：8–14 句（教學關可 12–18 句）
- **postBattleDialogue**：Boss 關 6–10 句；一般關 3–6 句
- **description**：2–3 句繁體中文，呼應當關劇情

## 禁止改動

- `id`, `chapter`, `level`, `mapId`, `maxWaves`, `modifiers`, `rewards`, `specialRules`, `isBossLevel`
- 不新增/刪除關卡檔案
- 不使用 emoji

## 文風

- 繁體中文，塔防軍事科幻 + 輕幽默
- 艾莉絲：專業、偶爾冷幽默
- 指揮官：沉穩、有軍人世家背景
- 外傳章節可切換 POV，但保持同一檔案內 speaker 一致
