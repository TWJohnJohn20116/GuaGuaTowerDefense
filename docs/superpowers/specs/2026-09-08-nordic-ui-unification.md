# 北歐指揮所 · 全介面統一規格

> 日期：2026-09-08  
> 版本：1.2.0（只改介面，不升版號）  
> 這份文件是之後改任何畫面的唯一對齊標準。跟它打架的樣式不要合併、不要開例外。

## 目標

把瓜瓜塔防所有介面重做成**同一個專案**：同一套頂列、同一顆返回鈕、同一種卡片、同一種按鈕、同一種字級。  
玩家從主選單走到商店、圖鑑、對局、暫停、結算，不該覺得進了另一款遊戲。

已核准方向：**北歐指揮所**（深底、單一冷色、字變大、少玻璃）。

## 調色（唯一）

| Token | 色碼 | 用途 |
| --- | --- | --- |
| `--nordic-bg` | `#0b0d11` | 全畫面底 |
| `--nordic-panel` | `#1c2430` | 卡片、側欄、檢視 |
| `--nordic-panel-2` | `#273140` | 按鈕底、次級面 |
| `--nordic-stroke` | `#3d4a5c` | 所有 1px 邊 |
| `--nordic-text` | `#f3f6fb` | 主文字 |
| `--nordic-muted` | `#b4becc` | 輔助文字 |
| `--nordic-accent` | `#89c4dd` | 唯一強調：主按鈕、選中、射程 |
| `--nordic-accent-ink` | `#0b0d11` | 強調按鈕上的字 |
| `--nordic-ok` | `#7dcaa8` | 成功／生命 |
| `--nordic-warn` | `#e0c37a` | 警告 |
| `--nordic-bad` | `#e07a7a` | 危險／出售 |

場景**不得**再為自己換一套底色（紫粉成功危險整頁漸層都禁止）。語意色只用在資料（血量、錯誤、可領獎），不用來換整頁皮膚。

## 形狀與字

- 圓角一律 **10px**（卡片、輸入、一般按鈕）。返回鈕 **8px**。
- 邊框一律 **1px `--nordic-stroke`**。選中改 1px `--nordic-accent`，不要 ring-offset 彩虹。
- **禁止** `backdrop-blur`、`shadow-2xl`、`rounded-3xl` 以上、漂浮粒子、雙色光暈球。
- 頁標題：**18px / 700**，不要全大寫、不要 `tracking-widest`。
- 內文：**13px**。輔助：**12px muted**。數值用等寬數字。
- 圖示只用 SVG，不用表情符號。

## 五種佈局（沒有第六種）

任何畫面只能選下面一種。新畫面先對表，再寫 JSX。

### 1. Home（只有主選單）

左欄 320px：品牌、狀態、主行動（開始防衛 / 選地圖）。  
右欄：等寬入口卡，3 列。沒有外層大玻璃盒。

### 2. Page（次頁單欄）

頂列固定 56px：左 **36×36 返回** + 標題 + 可選副標；右可放搜尋或一個主行動。  
下方單欄內容，最大寬 1120px，左右 24px。  
用於：更新日誌、教學、戰績列表、紀念堂列表、成就、天賦（若無側欄）、失敗／勝利結算。

### 3. Split（頂列 + 側欄 + 主區）

頂列同 Page。  
左欄 **200px** 導航（設定分類、圖鑑分頁、商店分類、選圖清單）。  
右欄主內容。側欄與主區都是 `--nordic-panel` 卡，不是兩種不同圓角。  
用於：設定、圖鑑、商店、皮膚、選地圖、每日／突變挑戰、回放、工坊、Mod 管理／編輯、地圖編輯。

### 4. Battle（對局）

不要套 SceneShell 粒子底。戰場全幅。  
- 頂：一條 HUD（生命、金錢、波次、速度、暫停）  
- 底：塔塢橫列  
- 右：選中塔檢視（升級／出售／技能）  
2D / 3D 共用同一套 HUD 元件，只換畫布。

### 5. Overlay（蓋在現有畫面上）

半透明黑遮罩 + **一張**置中卡（寬 320–420）。  
按鈕直向全寬，主行動用 accent。  
用於：暫停、對話、互動教學、Boss 警告、合體橫幅、成就／更新通知、載入。

## 元件契約

### 返回鈕

全專案只准用 `BackButton`。  
預設：36×36、8px 圓角、chevron SVG、可選「返回」文字。  
禁止各場景自己畫一個箭頭。

### 頂列

全 Page / Split 必須用 `SceneShell.Header`（或之後抽出的 `NordicTopbar`）。  
高度 56px，返回與標題垂直置中。不要標題再套 48px 彩虹徽章。

### 卡片

`SCENE_GLASS.*`（名稱保留以免大爆改）實際 class 必須是北歐實色，不是玻璃。  
新碼優先用這些 token，不要手寫 `bg-white/5 backdrop-blur`。

### 按鈕

- 主：底 `--nordic-accent`，字 `--nordic-accent-ink`  
- 次：透明 + stroke  
- 危險：字或邊用 `--nordic-bad`，不要整顆彩虹紅玻璃

### 開關／輸入／分頁

設定頁、暫停設定、商店篩選，控件外觀必須同一套（`ToggleSwitch`、`CustomInput`、同一 chip）。

## 落地順序

1. Token + `SCENE_GLASS` + `SceneShell` + `BackButton`（本階段）  
2. 主選單改 Home  
3. 所有 Page  
4. 所有 Split  
5. Battle HUD  
6. Overlay  

每階段完成後，對表打勾：頂列是否同一、返回是否同一、卡片是否同一、強調色是否只有冷青。

## 明確禁止

- 各場景獨立「主題色整頁換皮」  
- 9–11px 全大寫 `tracking-widest` 當副標  
- 外層再包一層巨大玻璃 Bento  
- 對局再發明第四種面板圓角  
- 為了好看而加新字體、漸層字、彩虹邊
