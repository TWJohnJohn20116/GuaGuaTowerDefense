08遊戲主迴圈 最核心

一句話：useGameSceneEffects 開一條 requestAnimationFrame 迴圈， 每幀把「真實時間差 × 倍速」當 deltaTime，依序推進 10 個階段。渲染是另一條獨立迴圈，只讀狀態。

// src/components/scenes/game-scene/useGameSceneEffects.ts
const frameGuard = createFrameLoopGuard({ label: 'game-loop' });

const gameLoop = (currentTime) => {
  frameGuard.run(() => runFrame(currentTime));  // 單幀異常只掉一幀
  perfTickFrame();                              // 效能統計
  animationFrameId = requestAnimationFrame(gameLoop); // 排下一幀，永遠執行得到
};
歷史事故：generateId 忘了 import → 殺死「生產型敵人」時拋錯 → 下一幀排程寫在 callback 尾端 → 整局永久停格。 現在 frameLoopGuard 用 try/catch 包住單幀，並對重複錯誤節流（2 秒內只上報一次）。
