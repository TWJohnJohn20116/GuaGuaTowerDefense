# 瓜瓜塔防遊戲

一個功能完備的現代化塔防遊戲，使用 Tauri 2 + React 18 + TypeScript 開發，採用北歐風格深色主題。

## 遊戲特色

### 核心玩法
- 🗼 **18 種塔類型**：基礎塔、狙擊塔、加農炮、機槍塔、散彈塔、弩炮塔、冰凍塔、毒塔、雷射塔、電擊塔、火焰塔、錢塔、風塔、脈衝塔，以及 4 種融合塔（暴風塔、瘟疫塔、攻城塔、颶風塔）
- 👾 **22 種敵人類型**：普通、快速、精英、極速、坦克、重型、Boss、小Boss、飛行、治療、生產、護盾、隱身、狂戰士、裝甲、法師、蟲群、幽靈、爆破、破壞、干擾、護航，各有獨特機制
- 🌊 **波次系統**：15 波標準關卡 + 無盡模式（動態難度曲線）
- ⬆️ **升級系統**：塔 5 級升級 + A/B 分支路線 + 塔主動技能
- 💰 **資源管理**：金錢、生命值、分數系統
- 📜 **戰術協議**：每完成奇數波三選一，即時補給或改變下一波戰鬥規則

### 元遊戲系統
- 🌳 **天賦樹**：經濟 / 攻擊 / 防禦三大類別，15+ 節點含 Keystone，通關獲得天賦點數
- 🏆 **成就系統**：多分類成就含稀有度，進度追蹤與通知，含遊玩風格分析（Playstyle Isms）
- 🎨 **皮膚系統**：全塔多款皮膚（普通～傳說稀有度），含套組與 3D 預覽
- 🛒 **商店系統**：塔解鎖 + 9 個主動技能購買，網格瀏覽 + 詳情面板

### 遊戲模式
- 📖 **戰役模式**：17 章完整劇情，每章多關含對話系統，角色貫穿主線與外傳
- 📅 **每日挑戰**：每日隨機條件，歷史記錄與獎勵
- ⚡ **突變挑戰**：特殊規則挑戰，含頭像統計
- 🤖 **AI 自動戰鬥**：4 種策略（平衡 / 經濟 / 侵略 / 防守），自動建塔、升級、技能釋放

### 創作工具
- 🔧 **Mod 編輯器**：自訂塔 / 敵人 / 地圖 / 波次，含驗證、即時預覽、平衡分析、3D 模型編輯器
- 🗺️ **地圖編輯器**：完整地圖繪製，支援叉路系統（進階地圖）、障礙物
- 🏭 **創意工坊**：Mod 管理、匯入匯出、啟用停用

### 輔助功能
- 🎬 **回放系統**：插值平滑播放（顯示器幀率）、倍速、圖表分析、時間軸、筆記標籤
- 📊 **統計系統**：遊戲歷史記錄、模式統計、匯出功能
- 📚 **百科全書**：塔 / 敵人 / 地圖 / 難度 / 狀態效果 / 玩家技能詳情
- 🏛️ **紀念館**：通關記錄展示與回顧
- 🎵 **音效系統**：BGM 專輯切換、音效、API 下載 + IndexedDB 快取
- 🎓 **教學系統**：互動式與教學頁面雙模式，含進階戰術、遊戲模式說明
- 🌐 **多語言**：8 國語言完整支援
- ✨ **3D 模式**：Three.js 渲染，2D/3D 一鍵切換，GPU 粒子、實例化渲染
- 🖥️ **HUD 自訂**：佈局位置 / 大小 / 顏色 / 透明度 / 模糊強度自由調整

## 技術架構

| 層級 | 技術 |
|------|------|
| **桌面框架** | Tauri 2.x（權限模型、自動更新） |
| **前端** | React 18 + TypeScript |
| **3D 渲染** | Three.js |
| **樣式** | Tailwind CSS |
| **動畫** | Framer Motion |
| **狀態管理** | Zustand（persist 中介層持久化） |
| **建構工具** | Vite（手動分塊策略） |
| **Markdown** | react-markdown + remark-gfm |

## 安裝和執行

### 開發模式

1. 安裝依賴項：
```bash
npm install
```

2. 啟動開發伺服器：
```bash
npm run tauri dev
```

### 建構發布版

```bash
npm run tauri build
```

### 其他指令

```bash
npm run verify:isms    # 驗證遊玩風格定義完整性
```

## 操作說明

### 遊戲快捷鍵
| 按鍵 | 功能 |
|------|------|
| 左鍵點擊 | 選擇格子、建造或升級塔 |
| **P** | 暫停遊戲 |
| **ESC** | 返回選單 |
| **1 / 2 / 3** | 調整遊戲速度 |
| **Space** | 切換遊戲速度 |
| **⇧+1~9** | 釋放主動技能 |

### 遊戲規則
1. 每波敵人從起點（綠色格子）沿路徑前進到終點（紅色格子）
2. 玩家建造塔來阻止敵人到達終點
3. 每個到達終點的敵人減少基地生命值
4. 擊敗敵人獲得金錢，用於建造和升級塔
5. 成功擊退所有波次即可獲勝
6. 塔之間可以融合（兩座特定塔合體為更強的融合塔）

## 系統要求

- **作業系統**：Windows 10/11、macOS 10.15+、或 Linux
- **螢幕解析度**：建議 1280×720 以上
- **記憶體**：建議 4GB 以上（3D 模式需要獨立 GPU）
