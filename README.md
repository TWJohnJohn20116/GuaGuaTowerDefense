# 瓜瓜塔防遊戲

一個簡約現代風格的塔防遊戲，使用 Tauri + React + TypeScript 開發。

## 遊戲特色

- 現代化的 UI 設計，採用北歐風格深色主題
- 流暢的動畫效果（使用 Framer Motion）
- 多種塔類型（基礎塔、狙擊塔、加農炮、機槍塔、冰凍塔、毒塔、雷射塔、電擊塔、火焰塔）
- 多種敵人類型（普通、快速、坦克、精英、Boss、飛行、治療、生產）
- 波次系統，隨著波次增加敵人數量和強度
- 升級系統，可升級塔的屬性
- 資源管理系統，包括金錢和生命值
- 響應式設計，支援多種解析度

## 技術架構

- **框架**: Tauri 1.5
- **前端**: React 18 + TypeScript
- **樣式**: Tailwind CSS
- **動畫**: Framer Motion
- **狀態管理**: Zustand
- **建構工具**: Vite

## 操作說明

- **左鍵點擊**: 選擇格子、建造或升級塔
- **P**: 暫停遊戲
- **ESC**: 返回選單
- **1/2/3**: 調整遊戲速度
- **Space**: 切換遊戲速度

## 遊戲規則

1. 每波敵人會從起點（綠色格子）沿著路徑前進到終點（紅色格子）
2. 玩家需要建造塔阻止敵人到達終點
3. 每個到達終點的敵人會減少玩家的生命值
4. 擊敗敵人可獲得金錢，用於建造和升級塔
5. 成功擊退所有波次的敵人即可獲勝

## 系統要求

- 建議螢幕解析度 1280x720 以上
