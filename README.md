# 瓜瓜塔防

> 一款精心打造的塔防遊戲，使用 Tauri + React + TypeScript 開發

## 遊戲介紹

瓜瓜塔防是一款策略型塔防遊戲，玩家需要在地圖上放置各種防禦塔來阻止敵人入侵。遊戲包含多種塔類型、多樣化的敵人、豐富的地圖以及 AI 自動戰鬥系統。

## 遊戲特色

- **多種防禦塔** - 基礎塔、冰霜塔、火焰塔、毒液塔、機槍塔、金幣塔等，各具特色
- **豐富地圖** - 多張精心設計的地圖，支援隨機地圖生成
- **升級系統** - 防禦塔可升級強化，解鎖技能
- **AI 自動戰鬥** - 內建 AI 系統，支援平衡、經濟、進攻、防守四種策略
- **無盡模式** - 挑戰你的極限
- **成就系統** - 完成各種挑戰解鎖成就
- **自訂主題** - 支援多種主題配色
- **皮膚系統** - 自訂防禦塔和敵人外觀
- **教學系統** - 完整的新手教學引導

## 系統需求

| 項目 | 最低需求 |
|------|---------|
| 作業系統 | Windows 10 (64-bit) 以上 |
| 處理器 | 任何現代處理器 |
| 記憶體 | 4 GB RAM |
| 儲存空間 | 約 50 MB |
| 其他 | WebView2 Runtime（安裝程式會自動安裝） |

## 安裝方式

1. 前往 [Releases](https://github.com/TWJohnJohn20116/GuaGuaTowerDefense/releases/latest) 頁面
2. 下載最新版本的 `瓜瓜塔防_x.x.x_x64-setup.exe`
3. 執行安裝程式，依照指示完成安裝
4. 從開始選單或桌面捷徑啟動遊戲

## 操作說明

| 按鍵 | 功能 |
|------|------|
| 左鍵點擊 | 選擇格子、建造或升級塔 |
| P | 暫停遊戲 |
| ESC | 返回選單 |
| 1 / 2 / 3 | 調整遊戲速度 |
| Space | 開始波次 |

## 資料儲存

遊戲資料儲存於：
```
%APPDATA%\com.guagua.towerdefense
```

## 更新方式

下載最新版本的安裝程式並重新安裝即可，遊戲資料不會遺失。
